# Версия для компьютера

Тот же принцип, что у приложения для iPhone, но на Windows: звук с микрофона делится на
реплики по паузам, каждая реплика получает отпечаток голоса и превращается в текст.
Распознаванием занимается локальная модель Whisper (проект whisper.cpp): интернет не нужен,
звук никуда не отправляется.

Это пробная версия для проверки того, как всё устроено, ещё до урока.

## Запуск

Дважды щёлкни `start.bat` (или ярлык на рабочем столе). Откроется страница приложения, а в
окне консоли будут видны действия сервера. Чтобы остановить приложение, закрой это окно.

В первый раз браузер спросит разрешение на микрофон — разреши значком камеры в адресной строке.

## Как пользоваться

- **Слушать микрофон** — начинает расшифровку. **Остановить** — заканчивает текущую реплику и останавливает.
- **Открыть запись…** — прогоняет звуковой или видеофайл через то же самое. Файл можно также перетащить на страницу.
- Правая кнопка на реплике — отметить, кто говорил: «Это учитель» или «Это не учитель». После нескольких отметок
  тех и других остальные реплики подписываются сами. Отметка «Кто говорил?» означает, что программа пока не может решить.
- **Чувствительность** — насколько громче шума должен быть звук, чтобы считаться речью. Если счётчик показывает «речь»
  от шума, двигай ползунок вправо; если тихая речь не замечается — влево.
- **Пауза между репликами** — после какой паузы реплика считается законченной.
- **Сохранить в файл** — выгружает расшифровку текстом. **Журнал** — показывает, что делало приложение;
  журнал можно скопировать и прислать, если что-то пошло не так.

Расшифровка и отметки хранятся в браузере и остаются после перезапуска. Кнопка **Очистить** удаляет их.

## Если что-то не так

- «Распознавание не запущено» — проверьте, что рядом с папкой `app` есть папки `runtime` и `cache` (см. «Устройство»).
- «Микрофон не включился: доступ запрещён» — разрешите микрофон для страницы `127.0.0.1` в настройках браузера.
- Реплики появляются с задержкой в несколько секунд — распознавание считает процессор, а не видеокарта.
  На компьютере с Windows 11 может быть включена защита Smart App Control, которая не пускает свежие сборки
  для видеокарты; рабочая сборка в таком случае подбирается опытным путём (см. `tools/check_build.py`).

## Устройство

```
app/            эта папка: server.py, страница (web/), тесты (tests/), инструменты (tools/)
runtime/        программа распознавания (whisper, whisper-cuda) и модель (models/ggml-small.bin)
cache/          журналы распознавателя и пробные записи (cache/demo)
```

Всё, что занимает много места, лежит в `runtime` и `cache`. Чтобы перенести приложение на другой диск,
переместите папку целиком.

`server.py` использует только стандартную библиотеку Python (нужен Python 3.9 или новее) и ничего не скачивает.
Логика страницы — обычный JavaScript без сборки. Тесты логики: `node --test tests/`.
