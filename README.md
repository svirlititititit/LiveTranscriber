# LiveTranscriber

iOS-приложение, которое превращает речь вокруг в текст. Звук с микрофона распознаётся
встроенным в iOS распознаванием речи Apple (на устройстве или на сервере), поток
делится на реплики по паузам, и каждая реплика сохраняется в расшифровку с меткой
говорящего.

Это ранняя пробная версия. Её цель — проверить на настоящем устройстве, как хорошо
слышно далёкого говорящего и насколько точным получается текст.

## Как устроено приложение

- **Распознавание речи** — `SFSpeechRecognizer` для русского языка. Одна реплика — один
  запрос распознавания. Если запрос оборвался, он перезапускается со всем накопленным звуком.
- **Разделение на реплики** — по громкости: речь начинается, когда звук становится
  заметно громче фонового шума, и заканчивается после долгой паузы (`SpeechGate`).
- **Метка говорящего** — упрощённый спектральный отпечаток голоса (`Voiceprint`). Это
  подсказка, а не надёжное распознавание: пользователь отмечает несколько реплик
  учителя и нескольких других людей, и новые реплики сравниваются с этими примерами.
- **Журнал** — последние события приложения видно на экране и можно отправить текстом.

## Сборка

При каждой отправке в ветку `main` GitHub Actions собирает приложение на виртуальном Mac
(workflow «Build»). Готовый `LiveTranscriber.ipa` лежит в артефактах запуска. Приложение
собирается без подписи: подписывает его то средство, которым его ставят на устройство.

Сборка на своём Mac:

```sh
brew install xcodegen
xcodegen generate
open LiveTranscriber.xcodeproj   # затем Product → Archive
```

## Тесты ядра

Логика разделения реплик, обработки сигнала и отпечатка голоса не зависит от iOS и
проверяется на Linux:

```sh
swift test
```

## Версия для компьютера

В папке `desktop` — порт для Windows: та же логика (деление на реплики по паузам,
упрощённый отпечаток голоса), но распознаванием занимается локальная модель Whisper
(проект whisper.cpp), а интерфейс открывается в браузере. Интернет не нужен, звук
никуда не отправляется. Подробнее — в `desktop/README.md`.
